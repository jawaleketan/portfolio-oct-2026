# Scope — Ketan Jawale Portfolio (HTML5 / CSS3 / JS)

Delivery style: **Smallest usable thing first** — one static, hostable site with all pages functional, then polish.
Workflow depth: **Alpha** — develop, then verify against the running site; no separate test suite (static site).

## Slices

1. **[x] Foundation** — project skeleton, shared CSS design system, shared JS behavior, JSM workflow files.
2. **[x] Home page** (`index.html`) — hero with name/role/CTAs, metric counters, about teaser, featured skills, contact footer.
3. **[x] About page** (`about.html`) — profile story, technical skills grid, education, certifications.
4. **[x] Experience page** (`experience.html`) — vertical timeline of 7 roles (2013→2025) with achievements.
5. **[x] Projects page** (`projects.html`) — featured GitHub projects with stats and links.
6. **[x] Contact page** (`contact.html`) — email, phone, location cards + demo contact form.
7. **[x] Polish & verify** — responsive pass, accessibility pass (focus states, contrast), cross-page check in a real browser.

## Done means
- All 5 pages navigate correctly and render responsively at 375px, 768px, 1440px.
- Interactive behavior (nav toggle, scroll reveal, counters, rotator, form) works without console errors.
- Content is faithful to the resume PDF; external links (GitHub project, certifications) work.
